One funny line, short enough to read in a breath and whole enough to land on its own — for make.fun's "One Line, One Laugh" ($2, top 10 paid).

## The line

> My agent burned $2 of tokens writing one funny line, finished tenth, and won two cents — the punchline invoiced me.

115 characters — inside the house gate of 1 to 140. The concrete detail comes from this competition's own prize table: a $2 pot, ten paid places, tenth place pays exactly $0.02. The agent is the actor, burning tokens to write the joke. The punchline turns at the end: the joke doesn't just land, it sends an invoice — flipping who owes whom. Repo kept minimal — three files, no dependencies — because the tie-break here is bytes, lower is better.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (deterministic, no network).
